# Flashcards LoL

Site de flashcards pour apprendre League of Legends : sorts des champions, sorts en vidéo, runes et objets.

- **En ligne** : https://tomfro.github.io/flashcards-lol/ (sur PC ou téléphone). Le bouton « Télécharger pour hors ligne » de chaque section garde ses données dans le navigateur pour jouer sans internet.
- **Sur PC, hors ligne** : télécharge le dossier, double-clique sur `mise-a-jour.bat` (télécharge les données et images de Riot dans `data/`), puis ouvre `index.html`. `telecharger-videos.bat` ajoute les vidéos des sorts (1 à 2 Go).

Touches : `Espace` retourner la carte, `1` à revoir, `2` je savais, `P` `A` `Z` `E` `R` fiche détaillée du sort.

Données : Riot Data Dragon, Meraki Analytics (valeurs des sorts). Projet non officiel, non affilié à Riot Games.
